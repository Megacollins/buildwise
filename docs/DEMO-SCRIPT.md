# Construction Desk — demo script (about 3 minutes)

Before recording: `npm run desk:demo -- http://localhost:3210`, create the room from the template
with the printed project name, sign in to Buildwise as the owner in a separate browser window.

| # | Time | Screen | Say / do |
|---|---|---|---|
| 1 | 0:00 | Buildwise project overview | "A family is building in Lagos. The design, plans, quantities and cost all come from one building model in Buildwise." |
| 2 | 0:20 | Switch room | "The team works in a Switch room with a Construction Desk agent. It can only use seven Buildwise tools — no shell, no files, no web." |
| 3 | 0:35 | Room: `@desk give me a short status…` → Allow for this session | Point at the Allow card: "Every tool call is put to a person in the room." |
| 4 | 0:55 | Room: `@desk we need to bring the cost down…` | "These savings aren't guesses — Buildwise re-runs its cost engine on each option." |
| 5 | 1:20 | Room: `@desk propose option 2` → Allow once | Show the before/after table and the approval link. "It's recorded as pending — nothing has changed yet." |
| 6 | 1:40 | Room: `@desk apply it` | "Allowing the tool in Switch isn't approval. The agent sees it's still pending and stops." |
| 7 | 1:55 | Buildwise approval page | Scroll the quantity and cost-line tables. Add a note. **Approve change.** "Only the project owner, signed in, can do this." |
| 8 | 2:20 | Room: `@desk the owner approved it, apply it` → Allow once | "Now it applies — as a new version." |
| 9 | 2:35 | Buildwise Versions tab | Show "Approved change: …", the agent change record with the note, and that earlier versions are kept. |
| 10 | 2:50 | — | "Switch is where the decision is made together; Buildwise is where it's checked, priced and recorded." |

Keep the actual numbers on screen; don't read out figures that aren't shown.
